# NovaTech Landing Page

A modern and responsive one-page landing page for **NovaTech Solutions**, a fictional software company.

## 🚀 Project Overview

This project was built as part of my 90-day Software Engineering Apprenticeship to strengthen my frontend development skills by focusing on semantic HTML, responsive design, and clean code practices.

## ✨ Features

- Responsive navigation bar
- Hero section
- About section
- Services section
- Why Choose Us section
- Testimonials
- Contact form
- Footer

## 🛠️ Built With

- CSS3
- JavaScript (Vanilla)
